# 02 市场调研与供给情报

用于纯市场调研、市场扫描、玩家发现、供应商信息整合、价格信号和风险事实整理。

处理此类请求时，完整读取并遵循 [it-sourcing-map](../../skills/it-sourcing-map/SKILL.md)。该专项 Skill 是本工作流的唯一详细执行规范；不要在这里另套华为五看、CIPS、CPPM、固定三段式或强制 HTML。

边界：

- 直接完成需求理解、动态市场分层、玩家扫描、厂商事实卡、价格/商业模式、风险、趋势、Long List 和来源台账；
- 默认大陆企业占候选池严格多数并优先展示，海外企业作为专项能力、替代路线或市场参照补充；主体不清时明确待核验，不得猜测；
- 公开价格与行业估算分开，事实、供应商声明、推断和未知项分开；
- 不输出推荐名单、适配度、评分、淘汰结论、联系顺序或采购动作；用户明确要求决策时，再转入选型、准入或推荐工作流；
- HTML 只是可选展示载体。交付是否完成，以采购人员能否看懂市场、玩家、价格、风险和证据为准。
