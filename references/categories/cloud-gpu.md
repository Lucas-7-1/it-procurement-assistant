# 云与 GPU / 算力采购

## 最小需求字段

- 工作负载、地域、环境、运行窗口、增长、容灾和数据驻留要求。
- CPU/GPU/内存/存储/网络规格，实例或卡型，集群规模，峰均值和利用率。
- 训练、推理、批处理或通用计算；对吞吐、时延、显存、互联和可用容量的要求。
- 按需、预留/承诺、竞价/可中断、包年包月和弹性比例。
- 托管服务、软件许可、镜像、支持、监控、安全和迁移需求。

## 成本归一

统一实例/卡型、地域、运行小时、折扣期、币种和计费粒度，拆分：

- 计算/GPU、系统盘与对象/块存储、快照和备份；
- 公网/跨区/跨地域流量、专线、负载均衡和 IP；
- 托管数据库/容器/AI 平台、监控日志、安全和支持计划；
- 软件许可、容量预留、闲置、迁移和退出数据传输。

至少计算单位有效 GPU 小时/训练任务/成功推理成本、承诺利用率、闲置率和低/中/高增长情景。标称卡时不可直接等同有效算力；需要性能基准和实际利用率。

## POC 与评价

- 在相同镜像、数据、模型、框架、精度和时间窗下测吞吐、延迟、稳定性、扩缩容和有效利用率。
- 验证容量可得性、配额审批、集群互联、存储/网络瓶颈、故障恢复、监控与成本可见性。
- 演练可中断资源回收、跨区故障、容量不足和数据迁移。
- 区分硬件理论性能、云平台调度能力和运维服务能力。

## 商务与供应策略

- 在基线负载上使用承诺/预留，在不确定和峰值负载上保留弹性；用情景分析决定比例。
- 谈清承诺可调整/转移、未用额度、超量、价格保护、容量保证、配额、支持和服务积分。
- 评估单云、双云或主备策略的迁移复杂度、数据重力、网络费用、工具锁定和运维成本。
- 对紧缺 GPU，合同同时约定具体资源、地域、交付窗口、未交付补救和替代规格，避免只锁价格不锁容量。

## SLA 与合同重点

- 可用性、容量交付、性能口径、支持响应、事件通知、RTO/RPO 和服务积分。
- 价格/产品下线通知、承诺计划、配额、区域变更、数据驻留、审计和子处理方。
- 数据导出、出网费用、镜像/配置/IaC 可移植、终止协助和删除证明。
- 服务积分不必然覆盖业务损失；对关键负载定义连续不达标的升级、替代资源和退出权。

## 运营指标

跟踪成本、预算偏差、利用率、闲置/孤儿资源、承诺覆盖与利用、单位工作负载成本、容量满足率、故障、出网费用和异常涨幅。区分业务增长与浪费。
