# IT 采购助理

一个面向甲方 IT 间接采购的自然语言助手。

你只需要说明遇到的问题，或者上传现有材料；Agent 会自行判断应该分析什么、核对什么、计算什么，并直接交付可执行结果。

> 你负责描述需求，Agent 负责判断方法并完成工作。

## 核心体验

你不需要：

- 判断现在属于哪个采购阶段；
- 选择工作模式、流程或“第几招”；
- 先挑选模板或填写完整问卷；
- 理解技能背后的文件结构和处理逻辑。

资料暂时不完整时，Agent 会先完成能够确认的部分、明确必要假设，并只追问真正会改变结论的关键信息。

## 能帮你处理什么

| 你的实际问题 | 可以直接拿到的结果 |
|---|---|
| 需求还比较模糊，不确定是否应该采购 | 需求澄清、采购边界、供给策略和下一步建议 |
| 想了解市场或寻找合适供应商 | 市场判断、候选名单、准入风险和推荐理由 |
| 几家供应商不知道怎么选 | 比较口径、评分依据、关键差异和明确推荐 |
| 需要设计 Demo、POC 或技术评估 | 测试场景、通过标准、证据清单和评估结论 |
| 报价看不懂或需要谈判 | 报价归一、TCO 测算、价格问题和谈判话术 |
| 合同或 SLA 需要采购侧审阅 | 风险条款、影响说明、修改建议和替代文本 |
| 项目出现延期、变更或交付问题 | 履约判断、责任与证据缺口、整改和沟通方案 |
| 需要验收或审核付款条件 | 验收/付款证据核对、风险和放行建议 |
| 供应商表现不好或即将续约 | 绩效判断、整改要求、续约/换供/退出建议 |
| 需要向领导汇报或申请拍板 | 一页式结论、选项比较、风险和拍板事项 |

## 重点支持的采购品类

- 大模型、MaaS、模型 API、推理服务；
- AI Coding、企业 AI 编程助手；
- 公有云、GPU、算力及相关基础设施；
- 企业 SaaS、软件订阅和实施；
- IT 咨询、开发、运维、外包等专业服务。

其他 IT 间接采购场景也可以直接提出，Agent 会根据实际材料处理。

## 怎么使用

启用本 Skill 后，像平时和同事沟通一样直接描述需求即可。可以只说问题，也可以同时上传需求书、报价单、合同、评分表、项目周报、账单、使用数据或会议纪要。

例如：

- “帮我看看这三家报价，统一口径后直接推荐一家，并告诉我怎么谈。”
- “这是供应商合同，找出采购侧最需要改的风险条款，给我替代文本。”
- “这个 AI Coding 工具要续约了，结合席位和活跃数据判断续多少、价格怎么谈。”
- “项目延期两周，供应商说是需求变更导致的。根据这些材料判断责任，帮我写回复。”
- “核对这笔里程碑付款是否满足条件，有问题的地方列出来。”
- “把这些材料整理成一页给领导拍板，结论放在最前面。”

如有明确要求，可以顺便说明受众和格式，例如“给领导看”“写成邮件”“做成对比表”“控制在一页内”。没有指定时，Agent 会自行选择最适合交付的形式。

## 默认会怎么交付

- 先给结论、推荐或最重要的判断；
- 给出足够支撑结论的事实和计算；
- 标出关键风险、影响及处理动作；
- 区分已确认事实、计算结果、暂用假设和未验证信息；
- 需要对外沟通时，提供可直接复制发送的文本；
- 需要推进项目时，给出具体下一步和责任角色。

Agent 不会编造价格、资质、案例、合同或供应商事实。涉及当前市场、产品、法规或供应商状态时，会在具备联网能力的环境中核验并附来源。技术、法务、财税、审批和付款的最终决定仍由相应授权人作出。

### 专项寻源 Skill（一句话 → HTML）

[it-sourcing-map](skills/it-sourcing-map/) 负责轻模式寻源：**丢一句话需求进去，Agent 自动按“五看三定”做实时调研，直接甩一个离线 HTML 分析出来**。

- 五看：看行业（含国家政策、技术趋势、行业竞争格局）、看市场、看客户（同行/友商采用路径）、看竞争（竞品与行业玩家）、看自己；
- 三定：定控制点、定目标、定策略；
- HTML 内容：需求原话与假设、五看证据卡（来源可回链）、三定、供应商分布地图（可筛选）、入围/观察/排除短名单、合规风险热区、来源清单；
- 全程不问卷、不确认中间产物；信息缺口自动记为假设或待确认。

示例（直接发一句话即可）：

- “想给 200 人研发团队采购 AI 编程助手，帮我看看市场”
- “我们要上一套客服大模型推理服务，扫一下国内有哪些供应商”
- “GPU 算力租赁市场现在什么情况，用五看三定分析一下”

也可附带需求文档，文档事实优先于一句话推断。

- 显式调用：`$it-sourcing-map`
- 打包文件：[it-sourcing-map.zip](dist/it-sourcing-map.zip)

安装或加载后，无需记忆调用命令，直接描述采购需求即可。
