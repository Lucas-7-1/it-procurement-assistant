# 谈判方案 Few-shot 示例（品类：企业 SaaS）

## 输入

**用户一句话诉求**：CRM 年费报价 80 万，超预算 15%，本季度内必须签下来，帮我出个谈判方案。

**背景要点**：
- 现报价 80 万/年（列表价），预算上限 68 万/年；POC 已通过，业务方倾向该厂商
- 备选供应商 B 报价 62 万/年，功能覆盖率略低但可用（BATNA 成立）
- 我方用户数预计一年内从 200 增长到 350；供应商财年 Q4 即将结束

## 输出（结构化谈判方案）

### 1. 目标价依据
- 目标价 **66 万/年**（列表价约 8.2 折）：同等规模企业成交价通常为列表价 7-8 折（Gartner/Forrester 基准）
- 底线价 70 万/年：仍在预算可申请浮动区间内；低于备选方案切换成本后的等效价
- 锚点报价 60 万/年开谈，留出让步空间

### 2. 杠杆选择（按优先级）
| 杠杆 | 理由 |
|------|------|
| 季末/财年末时点 | 对齐供应商 Q4 冲刺，历史上可换 10-25% 额外折扣 |
| 竞争性报价 | 供应商 B 62 万报价为可信价格锚 |
| 多年期锁价 | 用户数 200→350 的增长故事对其 ARR 有价值，2 年期可换 10-15% 折扣 |
| BATNA 表达 | POC 虽通过但未对外承诺，切换仍可行 |

### 3. 话术模板（取自调研素材 R3 板块四）
- **季末时点（邮件）**："我们正在推进本季度内的采购决策。如贵司能在本月 25 日前提供有竞争力的报价，我方可以加快内部审批流程，争取本季度完成签约。请问定价上是否有灵活空间？"
- **竞争性报价（邮件）**："经过评估，我方已将选择范围缩小到两家。贵司是我们的首选方案（基于 POC 中的流程覆盖表现），但目前存在明显价格差距——竞品报价为 62 万/年。如能将价格调整到 66 万以内，我方本周即可确认合作意向。"
- **多年期承诺换锁价（会议口径）**："我方愿意考虑两年期合约，但前提是单价降至目标价并锁定全期不涨价。我们预计用户数将从当前 200 增长到 350，这对贵司的 ARR 稳定性有明确价值。"
- **抗辩应对（对方称"这是统一列表价，不打折"）**："我方了解到同等规模企业的成交价通常为列表价的 7-8 折，这也是 Gartner/Forrester 的基准数据。请贵司确认是否有 enterprise 定价方案。"
- **抗辩应对（对方称"明年必涨价 10%"）**："如果涨幅不可控，我方需要在合同中写入年涨幅上限（如 CPI+2%），否则我们只能签一年期，保留到期重新评估的权利。"

### 4. 让步-交换底线（每一个"给"必须换一个"得"）
| 我方可让（给） | 必须交换（得） |
|----------------|----------------|
| 签 2 年期而非 1 年 | 全期锁价 + 单价降至 ≤66 万/年 |
| 本季度内完成签约 | 额外季末折扣以书面报价确认有效期 |
| 配合客户案例/参考推荐 | 免费实施支持或 Premium 支持升级 |
| **不可让步** | 数据免费导出与迁移协助、年涨价上限 CPI+2%、无自动续约 |
